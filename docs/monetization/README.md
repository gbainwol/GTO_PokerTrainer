## Monetization roadmap

This folder outlines how to ship ads, subscriptions, and pricing for GTO PokerTrainer. The documents are intended to be implementation-ready, with concrete partners, placements, API contracts, and client behaviors.

### Contents
- `mediation_and_ads.md` — Partner selection per platform, placements, and frequency capping.
- `subscriptions_and_receipts.md` — Receipt validation service, webhooks, and failure handling.
- `pricing_and_paywalls.md` — Regional pricing matrix, client paywall flows, and "solve with ad" CTA logic.
